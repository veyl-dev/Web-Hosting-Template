# Deploying the NexHost template to Vercel

This is a static HTML, CSS, and JavaScript project. No build command, framework preset, environment variables, or server runtime is required.

1. Push the repository to GitHub.
2. In Vercel, choose **Add New → Project** and import `veyl-dev/Web-Hosting-Template`.
3. Leave Framework Preset as **Other**.
4. Leave Build Command and Output Directory empty.
5. Deploy.

The landing page is `index.html`; the client dashboard preview is `dashboard.html`.

If you use a custom domain, point it to the Vercel project using the DNS records Vercel provides.
